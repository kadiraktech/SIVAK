# 🔐 SIVAK – Hybrid Encryption System (C/Python)

**Quantum-resistant hybrid encryption prototype** combining classical and post-quantum cryptographic methods.  
Designed to secure files, communications, and digital assets against future quantum decryption threats.

---

### 🔍 Overview
SIVAK integrates **PQC (Post-Quantum Cryptography)** algorithms within a hybrid encryption pipeline.  
It fuses symmetric (AES-like) encryption for speed with quantum-safe public-key systems for key exchange.

- **Architecture:** Classical + Post-Quantum Hybrid
- **Purpose:** Secure file encryption, data privacy, future-proof protection
- **Core Design:** Modular and CLI-compatible

---

### 🧠 Tech Stack
| Tool | Purpose |
|------|----------|
| C | Core performance layer |
| Python (Cython) | Interface and automation |
| PQCrypto | Post-quantum algorithm library |
| CLI Tools | Command-line encryption control |

---

### 📊 Key Features
- File-level hybrid encryption & decryption
- PQC-based key generation
- CLI interface for automation
- Modular design for cross-platform integration
